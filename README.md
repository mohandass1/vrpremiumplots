# VR Premium Property Website

A responsive, premium real-estate landing website for VR Premium Property.

## Run
Open `index.html` in a browser.

## Customize
- Replace project placeholder sections with real project information.
- Add project photos in `assets/`.
- Update phone, WhatsApp, email and address in `index.html`.
- Add your Google Maps embed/link.
- Connect the enquiry form to WhatsApp, email or your backend.

- index.html
- style.css
- script.js
